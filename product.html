Security boundaries

Control remains with the user.

GCA AI Quant Access is designed around explicit permissions and transparent calculations.

No custody

GCA does not hold user funds or request transfer control.

No withdrawal access

The product does not request exchange withdrawal permission.

No secret collection

Never submit private keys, seed phrases, or exchange API secrets.

No automatic orders

Browser tools calculate and review; they do not place trades.

Official on-chain identity
