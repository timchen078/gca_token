会员路径

四步连接账户与服务。

请始终使用同一邮箱和 Base 钱包，让余额验证、持有证明和服务记录保持一致。

建立账户

在官方会员入口填写邮箱和一个 Base 钱包地址。

验证钱包

系统在 Base Mainnet 上只读查询当前 GCA 余额。

提交证明

达到会员门槛时，提交公开交易哈希和持有开始日期。

使用服务

在同一设备查看 credits、会员状态和服务申请。

资格规则

关键条件一页看清。

  • 账户规则每个邮箱和已验证钱包对应一个受控账户
  • 持有者门槛至少 10,000 GCA
  • GCA Member 门槛至少 1,000,000 GCA
  • 连续持有时间30 天
  • 会员证明公开交易哈希 + 持有开始日期
  • Credit 规则一次性 100 credits · 激活后 180 天有效
  • 会员权益会员通过后单独审核一次性 10,000 GCA

安全边界

只读验证，不接管钱包。

官方会员入口只收集公开账户和资格资料，不会要求私钥、助记词、钱包授权、签名、托管、交易所 API Secret 或提现权限。

Credits 和 GCA Member 状态不等于现金、收入、交易权限，也不会绕过产品风控。
